borrow
/ˈbɑːroʊ/

v. 借入；借用

I borrowed this travel guide from the library last week.
我上周从图书馆借了这本旅行指南。

记忆提示：borrow 是“向别人借来”；把书借给别人是 lend。

due
/duː/

adj. 到期的；应归还的

The book is due tomorrow.
这本书明天到期，应在那时归还。

记忆提示：把 due 看作“约定的到期点”：书 due tomorrow，账单也可 be due on Friday。

renew
/rɪˈnuː/

v. 续借；续期

I tried to renew the book online, but the app would not let me.
我试着在线续借这本书，但应用不允许。

记忆提示：re- 加 new：让借阅期限“重新延长”；续借能否成功仍要看规则。

overdue
/ˌoʊvərˈduː/

adj. 逾期的；过期未还的

The book will be overdue if I keep it past its due date.
如果过了归还日期还留着这本书，它就会逾期。

记忆提示：over + due：超过到期点。明天才到期的书，今天还不是 overdue。

return
/rɪˈtɜːrn/

v. 归还；退还

I will return the guide to the library this evening.
我今晚会把这本指南还给图书馆。

记忆提示：borrow 让物品暂时到手里；return 让它回到原处。

图书续借失败：到期前把书还清楚

以下是虚构的图书馆情境。一本旅行指南明天到期；读者原想续借，但应用显示已有他人预约，因而决定今天归还，并在应用里确认借阅记录已结束。续借和归还规则应以当地馆方信息为准。

用法辨析与易错点

borrow

辨析：borrow 表示从别人那里借入，lend 表示把自己的东西借给别人。I borrowed a book from the library 的主语是借书的人。

易错点：说 borrow a book from the library；不要说 borrow a book to the library 来表达“从图书馆借书”。

due

辨析：due 指应履行或归还的时间点；deadline 更常指完成任务的最后期限。图书场景中 The book is due tomorrow 很自然。

易错点：说 The book is due tomorrow 或 due on Tuesday；不要说 due in Tuesday。

renew

辨析：renew 是按规则续借或续期；extend 只是一般地延长。馆方批准后才能说 I renewed the book；点击申请不代表成功。

易错点：说 renew the book 或 renew the loan；不要说 renew the book back。

overdue

辨析：overdue 表示已超过应归还日期；due tomorrow 表示尚未到期。两词不能仅因“快到期”就互换。

易错点：说 The book is overdue 或 an overdue book；不要在到期日之前就断言它 is overdue。

return

辨析：return 是归还给原处；give back 更口语化。图书馆归还场景里 return the book to the library 清楚明确。

易错点：return 已含“回去”的意思，说 return the book 即可；不要说 return back the book。

应用练习

1. 你上周从图书馆借了一本书，明天到期。用 borrow 和 due 写一句话。
答案：I borrowed a book from the library last week, and it is due tomorrow.
解析：borrow ... from 标明借入来源；be due 表示应归还的日期。

2. 应用拒绝续借，因为别人预约了这本书。用 renew 写出原因。
答案：I cannot renew the book because someone else has placed a hold on it.
解析：renew 表示续借；placed a hold on it 说明该书已有预约。

3. 书明天到期，你今晚打算归还，避免逾期。用 return 和 overdue 写一句话。
答案：I will return the book this evening so it does not become overdue.
解析：今天归还早于明天的到期时间；become overdue 表示之后可能进入逾期状态。

读到 due date，先查能否 renew；若续借未获准，就按馆方规则及时 return。只有超过到期时间仍未归还，才称 overdue。
