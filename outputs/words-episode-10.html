评审前发现文件版本不对，怎样补救？

下午的预算评审前，同事发现邮件附件是旧成本表，而说明中的新表链接又没有开放权限。发件人先解决查看障碍，再据新数字修订说明并重发。以下是用于练习的虚构工作对话。

情境对话

Mia: Could you check the budget note before three? I've included the cost sheet as an attachment.
米娅：三点前能帮我看一下预算说明吗？我把成本表作为附件发过去了。
Leo: I opened the attachment, but it's outdated. The shipping estimate is from last week.
利奥：我打开了附件，但它不是最新版。运费估算还是上周的数据。
Mia: You're right. The note links to the latest sheet. Can you access it?
米娅：你说得对。说明里有最新版表格的链接。你能打开吗？
Leo: No. I don't have access to that sheet, so I can't check the new total.
利奥：不能。我没有那张表的访问权限，所以没法核对新总额。
Mia: I'll grant you access, revise the note using the latest total, and resend it with the correct attachment.
米娅：我会给你开通权限，按最新总额修改说明，再连同正确的附件重新发送。
Leo: Thanks. Once the new version arrives, I'll check the figures before the review.
利奥：谢谢。新版本收到后，我会在评审前核对数字。
attachment
/əˈtætʃmənt/

n. 附件；随邮件发送的文件

The attachment is last week's cost sheet.
附件是上周的成本表。

记忆提示：看到邮件里的回形针图标，联想 attachment：随邮件附上的文件。

辨析：attachment 指真正附在邮件里的文件；link 指向另一个位置。旧附件与新链接可以同时出现在同一封邮件中，核对时要分别说明。

易错点：说 attach the sheet to the email 或 include it as an attachment；不要说 attach the sheet in the email。

outdated
/ˌaʊtˈdeɪtɪd/

adj. 过时的；不是最新版本的

The shipping estimate in this sheet is outdated.
这张表里的运费估算已经不是最新的。

记忆提示：把 out of date 连起来记成 outdated：日期和版本都已经“过时”。

辨析：outdated 强调版本或信息已不再适用；incorrect 强调内容有错误。上周的估算当时可能正确，如今仍可能 outdated。

易错点：修饰名词用 an outdated sheet；不要把动词原形 outdate 直接放在 sheet 前。

access
/ˈækses/

n. 访问权限；使用权

I don't have access to the latest sheet.
我没有查看最新表格的权限。

记忆提示：把 access 想成进入文件的“通行证”；有链接不等于有通行证。

辨析：have access to the sheet 表示有查看权限；open the sheet 只描述打开动作。能看到链接不代表有 access。

易错点：名词要说 have access to the sheet；动词则说 access the sheet，不加 to。

revise
/rɪˈvaɪz/

v. 修改；修订（内容）

I'll revise the budget note using the latest total.
我会按最新总额修改预算说明。

记忆提示：把 revise 和 revision（修订版）一起记：先修改，才有新版本。

辨析：revise the note 是按新数字修订整份说明；correct the shipping figure 更聚焦修正一个具体错误。

易错点：revise 后直接接修改对象：revise the note；不要说 revise on the note。

resend
/ˌriːˈsend/

v. 重新发送

Please resend the note with the correct attachment.
请把说明连同正确的附件重新发送。

记忆提示：re- 表示“再一次”；重新发送前，先检查这次附的是否是正确版本。

辨析：resend 是把内容重新发给收件人；forward 是把收到的邮件转给别人。补发修订稿时用 resend。

易错点：过去式和过去分词是 resent，不是 resended；它与表示怨恨的 resent 拼写相同，读音不同。

应用练习

1. 附件是旧版，但共享表格的链接指向新版。用 attachment 和 outdated 向同事指出问题。
答案：The attachment is outdated; the linked sheet is the latest version.
解析：分别指出旧附件和新链接，避免笼统地说 the file is wrong。

2. 填空：I don't have ___ to the sheet, so I can't check the total.（access / an access）
答案：access
解析：表示一般访问权限时，access 在 have access to 中是不可数名词。

3. 发件人修改了预算说明，并把正确附件再次发出。用 revise 和 resend 写一句行动说明。
答案：I'll revise the note and resend it with the correct attachment.
解析：先修订内容，再重发；with the correct attachment 明确这次会附上正确文件。

处理版本问题时，先指出哪个 attachment 已 outdated，再核查新版文件的 access；修订说明用 revise，补发给原收件人用 resend。这样能把文件错误、权限障碍和补救动作逐一说清。
