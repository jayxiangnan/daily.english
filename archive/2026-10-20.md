# 每日 5 词 · 第 26 期（2026年10月20日）

## 今日 5 词

### 1. spam

/spæm/　n. 垃圾邮件；此处指被归入垃圾邮件的邮件

- Lena found the earlier reset email in her spam folder.
- 莉娜在垃圾邮件文件夹里找到了先前的密码重置邮件。

**搭配或句型：** check your spam folder 表示检查垃圾邮件文件夹；spam 作此义通常不可数。

### 2. request

/rɪˈkwest/　v. 请求；正式提出要求

- Lena requested a new password reset email through the portal.
- 莉娜通过网站请求了一封新的密码重置邮件。

**搭配或句型：** request a new email 中 request 直接接所请求的东西；名词可说 make a request for a new email。

### 3. link

/lɪŋk/　n. 网页链接；点击后可打开页面的入口

- The new email contained a link to the password reset page.
- 新邮件里有一个通往密码重置页面的链接。

**搭配或句型：** a link to a page 表示通往某页面的链接；click a link 是点击链接。

### 4. expire

/ɪkˈspaɪr/　v. 到期；过了有效期而不能再用

- The link in yesterday's email had expired, so Lena could not use it.
- 昨天那封邮件里的链接已经过期，莉娜无法再使用它。

**搭配或句型：** a link expires 表示链接到期失效；has expired 表示到现在已经失效。

### 5. reset

/ˌriːˈset/　v. 重新设置；此处指重设密码

- Lena used the new link to reset her password and sign in.
- 莉娜用新链接重设密码并登录。

**搭配或句型：** reset a password 是重设密码；动词过去式仍是 reset。

## 情境对话

### 密码重置邮件没到，旧链接又失效了怎么办？

示例情境：莉娜进不了课程网站，收件箱里也没有新的密码重置邮件。她请客服一起查找，发现昨天的邮件被分进垃圾邮件文件夹，但其中的链接已失效。人物、网站和处理过程均为教学设定。

- Lena: I can't sign in to the course portal, and the password reset email isn't in my inbox.
  - 莉娜：我登录不了课程网站，收件箱里也没有密码重置邮件。
- Agent: Could you check your spam folder and make sure you used the email address linked to your account?
  - 客服：请检查垃圾邮件文件夹，并确认你用的是与账户绑定的邮箱，好吗？
- Lena: The address is correct. I found yesterday's email in spam, but its link has expired.
  - 莉娜：邮箱地址没错。我在垃圾邮件文件夹里找到了昨天的邮件，但里面的链接已经失效。
- Agent: Then request a new reset email through the portal. Use the link in that new email, rather than yesterday's link.
  - 客服：那就通过网站请求一封新的重置邮件。请用新邮件里的链接，别再用昨天那条。
- Lena: I've requested it. The new link has arrived, and I can open the reset page.
  - 莉娜：我已经请求了。新链接到了，我能打开密码重置页面。
- Lena: I reset my password and signed in successfully. Thanks for helping me find the problem.
  - 莉娜：我重设了密码，已经成功登录。谢谢你帮我找到问题。

## 用法辨析与易错点

### 1. spam

**辨析：** spam 指不想收到的邮件；scam 指骗局。真正的重置邮件也可能被误分进 spam 文件夹，因此位置不能证明邮件真假。

**易错点：** 说 check my spam folder，不说 check my spams；点击重置链接前还要核对发件来源和网站。

### 2. request

**辨析：** request 比 ask 更正式，适合网站按钮或客服流程；对朋友说 ask for help 更自然。这里是通过网站提出新邮件请求。

**易错点：** 动词直接接宾语：request a new email；不要写 request for a new email，除非 request 作名词。

### 3. link

**辨析：** link 是可点击的入口；URL 是具体的网页地址字符串。邮件中可以点击 link，地址栏会显示 URL。

**易错点：** 说 a link to the reset page；不要把 link 和发来的整封 email 当成同一件事。

### 4. expire

**辨析：** expire 表示有效期结束；stop working 只说不能用了，不说明原因。昨天的链接已经过期，所以用 expired。

**易错点：** 此处用不及物表达 the link expired / has expired；不要说 I expired the link。

### 5. reset

**辨析：** reset a password 是重新设定密码；restart a device 是重新启动设备。莉娜需要改密码，不是重启电脑。

**易错点：** 过去式仍是 reset：I reset my password yesterday；不要写 resetted。

## 应用练习

1. 你找到了昨天的邮件，但链接已经失效。用 spam、link 和 expire 向客服说明。

2. 用 request 和 reset 写两句：你准备申请新邮件，并在收到后重设密码。

3. 换个情境：报名确认邮件中的链接过期了。选用本期两个合适的词，写一句英文请求新链接。

### 参考答案与理由

1. I found yesterday's email in my spam folder, but the link has expired.

   **解析：** spam folder 指邮件所在位置；has expired 说明链接现在不能再用。

2. I'll request a new reset email. When it arrives, I'll use its link to reset my password.

   **解析：** request 直接接 a new reset email；reset 接 my password。

3. The link in my registration email has expired. Could I request a new one?

   **解析：** link 指可点击入口，expired 说明其失效原因；request a new one 表示请求新链接。

**带走一句：** I found the email, but its link has expired. Could I request a new one?

我找到邮件了，但里面的链接已经失效。我能申请一条新链接吗？

收不到重置邮件时，先核对邮箱地址并检查 spam 文件夹；若找到的 link 已 expire，再 request 新邮件，并用新链接 reset 密码。
