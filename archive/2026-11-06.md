# 每日 5 词 · 第 40 期（2026年11月6日）

## 今日 5 词

### 1. column

/ˈkɑː.ləm/　n. 列；此处指表格中竖向的一列

- The names are in the first column.
- 姓名在第一列。

**搭配或句型：** the name column：姓名列。

### 2. row

/roʊ/　n. 行；此处指表格中横向的一行

- Each row has a name and a score.
- 每一行都有姓名和分数。

**搭配或句型：** in the same row：在同一行。

### 3. sort

/sɔːrt/　v. 排序；按某一规则排列

- Sort the whole table by score.
- 按分数给整张表排序。

**搭配或句型：** sort something by something：按某项给某物排序。

### 4. undo

/ʌnˈduː/　v. 撤销；取消上一步操作

- Undo the last sort before editing the table.
- 编辑表格前先撤销上一次排序。

**搭配或句型：** undo the last change：撤销上一次更改。

### 5. match

/mætʃ/　v. 与……对应；相符

- The scores no longer match the names.
- 分数不再与姓名对应。

**搭配或句型：** match the names：与姓名对应。

## 情境对话

### 只排序了姓名列，怎样找回每人的分数？

示例情境：小林给成绩表排序时只选了姓名列，姓名和分数错位。人物、数据及操作过程均为教学设定。

- Lin: I sorted the name column, but the scores stayed where they were.  
  林：我给姓名列排了序，可分数还留在原位。
- Mei: Then the scores may not match the names. Did you select the whole table?  
  梅：那分数可能和姓名对不上。你选中了整张表吗？
- Lin: No, only that column. In the first row, the name changed but the score did not.  
  林：没有，只选了那一列。第一行的姓名变了，分数却没变。
- Mei: Undo that sort first. Can you still see the original names and scores together?  
  梅：先撤销那次排序。你还能看到原本对应的姓名和分数吗？
- Lin: Yes. The original pairs are back.  
  林：能，原来的姓名和分数又对应上了。
- Mei: Now select the whole table and sort it by score. Check two rows against the original copy.  
  梅：现在选中整张表，按分数排序。再对照原始副本核查两行。
- Lin: I checked both rows. Each score still matches the right name.  
  林：我核查了这两行。每个分数仍与正确的姓名对应。

## 用法辨析与易错点

### column

**辨析：** column 是竖向的列；row 是横向的行。  
**易错点：** 说 the name column；不要把第一行表头误称为 first column。

### row

**辨析：** row 指横向的一组单元格；line 更常指线条或文字行。  
**易错点：** 本义读 /roʊ/；不要读成表示“争吵”的 /raʊ/。

### sort

**辨析：** sort by score 指依分数排序；filter by score 是按条件筛选可见记录。  
**易错点：** 表格中要让整行一起移动；只排序姓名列会使姓名和分数错位。

### undo

**辨析：** undo 取消上一步操作的效果；delete 是删除内容。  
**易错点：** 过去式是 undid，过去分词是 undone，不写成 undoed。

### match

**辨析：** match 强调两项相符或对应；equal 强调数值相等。  
**易错点：** 说 the scores match the names；不要用 equal 来表达姓名与分数的对应关系。

## 应用练习

1. 你发现姓名列单独移动了。用 column 和 match 说明问题。
2. 在重新排序前，怎样用 undo 说明第一步？
3. 新情境：值班表按日期排序，但员工姓名必须跟着所在行移动。用 row 和 sort 写出操作。

### 参考答案与理由

1. The name column moved, so the scores no longer match the names. 说明错位的原因和结果。
2. Undo the last sort first. undo 后直接接要撤销的操作。
3. Select the whole table and sort it by date so each row stays together. 按日期排序整张表，保持同一行的数据对应。
