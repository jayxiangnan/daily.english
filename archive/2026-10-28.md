# 每日 5 词 · 第 32 期（2026年10月28日）

## 今日 5 词

### 1. format

/ˈfɔːr.mæt/　n. 格式；此处指老师要求的 PDF 文件格式

- The assignment must be in PDF format.
- 这份作业必须是 PDF 格式。

**搭配或句型：** in PDF format：以 PDF 格式；file format：文件格式。

### 2. convert

/kənˈvɝːt/　v. 转换；此处指把 Word 文件转成 PDF

- I converted my Word document into a PDF.
- 我把 Word 文档转换成了 PDF。

**搭配或句型：** convert A into B：把 A 转换成 B。

### 3. preview

/ˈpriː.vjuː/　v. 预览；此处指提交前查看转换后的 PDF 页面

- Preview the PDF to make sure every page is complete.
- 预览 PDF，确认每一页都完整。

**搭配或句型：** preview the PDF before submitting it：提交前预览 PDF。

### 4. upload

/ʌpˈloʊd/　v. 上传；此处指把 PDF 文件传到课程平台

- Please upload the PDF to the course portal.
- 请把 PDF 上传到课程平台。

**搭配或句型：** upload a file to a portal：把文件上传到平台。

### 5. submit

/səbˈmɪt/　v. 提交；此处指正式交出已上传的作业供老师查看

- After uploading the file, click Submit to hand in the assignment.
- 上传文件后，点击“提交”正式交作业。

**搭配或句型：** submit an assignment：提交作业；submit it through the portal：通过平台提交。

## 情境对话

### 作业只收 PDF，手头是 Word 文件，怎样正确交上去？

示例情境：林准备交课程作业，却发现平台要求 PDF 格式，电脑里只有 Word 文件。她和同学核对要求后转换文件、预览页面，再上传并点击提交。人物、平台按钮和操作结果均为教学设定；实际要求与提交流程以课程说明为准。

- Lin: The course portal says the assignment must be in PDF format, but my file is a Word document.
  - 林：课程平台说作业必须是 PDF 格式，可我的文件是 Word 文档。
- Kai: Let me check the instructions. Yes, they say PDF only. Can you convert the document into a PDF?
  - 凯：我核对一下说明。没错，只收 PDF。你能把文档转换成 PDF 吗？
- Lin: I can. The PDF is ready, but the last page looks different. I should preview the whole file before sending it.
  - 林：可以。PDF 已经生成了，但最后一页看起来不一样。我应该先预览整份文件，再发出去。
- Kai: Good idea. Is the last page complete?
  - 凯：好主意。最后一页完整吗？
- Lin: Yes. I fixed a broken line in the Word document and converted it again. Now every page looks right.
  - 林：完整。我在 Word 文档里改好了那处断行，又转换了一次。现在每一页都正常。
- Kai: Then upload the new PDF to the course portal. Check the file name before you continue.
  - 凯：那就把新的 PDF 上传到课程平台。继续之前核对一下文件名。
- Lin: The correct PDF is uploaded. The page still shows a Submit button, so I haven't handed it in yet.
  - 林：正确的 PDF 已上传。页面上还有“提交”按钮，所以我还没正式交上去。
- Kai: Click Submit and check the confirmation message.
  - 凯：点击“提交”，再查看确认提示。
- Lin: Done. The portal says the assignment was submitted, and it shows the PDF file name.
  - 林：好了。平台提示作业已提交，还显示了 PDF 文件名。

## 用法辨析与易错点

### 1. format

**辨析：** format 指文件的类型或呈现方式；layout 更侧重页面上文字、图片的排布。老师限定 PDF 文件类型时，说 PDF format。

**易错点：** 说 in PDF format 或 as a PDF；不要把 format 当动词说 format my Word file into a PDF，此处应说 convert。

### 2. convert

**辨析：** convert 指从一种格式变成另一种；rename 只改文件名。把 .docx 后缀直接改成 .pdf，并没有完成格式转换。

**易错点：** 说 convert the Word document into a PDF；不要说 convert into a PDF the document。

### 3. preview

**辨析：** preview 是在正式交出前先查看成品；review 更侧重检查内容或质量。这里要看 PDF 页面是否完整，用 preview。

**易错点：** 说 preview the PDF；preview 本身就是动词，不必说 have a preview the PDF。

### 4. upload

**辨析：** upload 是把本地文件传到平台；download 是从平台取回本地。这里方向是电脑到课程平台，所以用 upload。

**易错点：** 说 upload the PDF to the portal；不要说 upload the PDF from the portal，后者容易把传输方向说反。

### 5. submit

**辨析：** submit 表示正式交给老师或系统处理；upload 只说明文件已传上去。在示例平台上，上传后还需点击 Submit。

**易错点：** 说 submit the assignment；过去式和过去分词是 submitted，要双写 t。

## 应用练习

1. 老师只收 PDF，你手头是 Word 文件。用 format 和 convert 写一句英文说明你的下一步。

2. 文件已经传到示例平台，但页面还显示 Submit。用 upload 和 submit 写两句英文，说明已完成和未完成的步骤。

3. 换个情境：求职网站要求 PDF 简历。你已转好 PDF，却担心末页被截断。用 preview 改写：‘I will send it now.’，表达先检查再发送。

### 参考答案与理由

1. The assignment must be in PDF format, so I'll convert my Word document into a PDF.

   **解析：** format 表示要求的文件格式；convert A into B 表示实际转换。

2. I've uploaded the PDF, but I haven't submitted the assignment yet.

   **解析：** 上传完成不等于正式提交；两个动作在此平台上分开。

3. I'll preview the PDF to make sure the last page is complete before I send it.

   **解析：** preview 指发送前看成品；before I send it 清楚交代先后顺序。

**带走一句：** I've uploaded the PDF, but I haven't submitted the assignment yet.

我已经上传了 PDF，但还没有正式提交作业。

遇到格式要求，先核对 format，再 convert 并 preview 文件；upload 后确认是否还需要 submit。
